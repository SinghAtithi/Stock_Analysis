## TASK 5 — Initial-load error UX + retry + staleness

1. **Initial load errors surfaced.** The old mount effect swallowed failures (`setData(null)`, no error). The initial load is now a self-contained async effect (`web/src/app/page.tsx:108`) that maps failures through the shared `errorMessage()` helper — `symbol not found` for `not_found`, server `json.error`, or `network error` — and always ends with `setLoading(false)`. `setError`/`setData` only run inside async callbacks to satisfy Next 16's `react-hooks/set-state-in-effect` lint rule (calling the `load()` callback in the effect body is flagged because it setState synchronously — first implementation attempt failed lint; see notes).
2. **RETRY button** inline next to the ⚠ badge (`page.tsx:360`): `border border-hairline px-2 py-1 font-mono text-[11px] tracking-widest text-paper hover:bg-panel`. `retry()` re-runs the current symbol load **and** re-triggers the ticker fetch via a `tickerNonce` dep on the ticker effect.
3. **Keyboard `r`** retries when focus is not in an input/textarea (extended the existing range-keys effect, `page.tsx:156`); ctrl/meta/alt combos are ignored so `Ctrl+R` still refreshes.
4. **aria-live="polite"** on the price/status region (with `aria-busy`) and on the error badge (`page.tsx:332,357`). The LOADING overlay inside `ChartPanel.tsx` is owned by another agent — not touched.
5. **Staleness chip** next to exchange/currency chips in the header (`page.tsx:318`): `border border-hairline px-2 py-1 text-faint` showing `timeAgo(data.regularMarketTime)` (e.g. `5m ago`, `14 Aug 2026` when stale), with an IST `title` tooltip. ChartPanel untouched.

## TASK 6 — Watchlist persistence (localStorage, anon-first)

- **`web/src/lib/watchlist.ts`**: `WatchlistEntry`, `DEFAULT_WATCHLIST` (the 7 original QUICK_PICKS), `loadWatchlist`, `addToWatchlist`, `removeFromWatchlist`, `isInWatchlist`, `exportWatchlist` (JSON string), `importWatchlist` (validates `symbol`+`exchange` strings, normalizes missing fields, merges unique, appends), key `niftyterm.watchlist`. Corrupt data resets to defaults; an explicitly stored empty array stays empty (so users can remove everything). Changes broadcast via `window.dispatchEvent(new CustomEvent("niftyterm:watchlist"))`; `subscribeWatchlist` also listens to the native `storage` event (cross-tab) and `localStorage.clear()` (`e.key === null`).
- **`page.tsx` refactor**: watchlist is a `useSyncExternalStore(subscribeWatchlist, getWatchlistSnapshot, getServerWatchlistSnapshot)` — hydration-safe (server renders defaults; client swaps in the persisted list without a mismatch, no setState-in-effect). `selected = picked ?? watchlist[0] ?? null`, so the initial symbol is the first persisted entry. Sidebar WATCHLIST renders from state with hover ✕ remove (`lg:opacity-0 lg:group-hover:opacity-100`), "LIST EMPTY — TAP THE STAR…" hint when empty, and removing the derived head advances selection to the new head. EXPORT (blob download `niftyterm-watchlist.json`) / IMPORT (hidden file input → `importWatchlist` → terminal-tone `window.alert`) live at the sidebar bottom (`mt-auto`).
- **StarToggle** (`StarToggle.tsx`): outline `lucide-react` `Star` when absent, filled `text-up` (#c6f534) + `border-up/40 bg-up/10` when present, `aria-pressed`. Sits in the symbol header next to the symbol chip — visible on desktop and mobile.
